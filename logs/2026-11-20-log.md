- 공개 저장소만 봐서는 어떤 앱인지 알 수 없다는 걱정이 나왔다. 인증키를 안 올려서, 받아서 돌리면 데이터가 안 나온다.
- 그래서 README 맨 위에 실제 화면 캡처를 넣었다.
- 「설치해야 하는 문제니까 zip 으로 드라이브에」라는 요청도 있었다. 그래서 설치 없이 도는 윈도우 실행 묶음을 만들었다.

## 실행 묶음 구성
- 작은 자바: jlink 로 `java.se` + 암호 · 한글 날짜 · 문자셋 모듈만 넣었다. 48MB다.
- 톰캣 11.0.25: 필요한 것만 넣었다. 서비스 exe · 예제 · 관리 앱 · 이 PC 설정(HelloWeb 등)은 뺐다. 17MB다.
- 앱: 소스에서 새로 컴파일한다.
- 크기: 폴더 65MB, zip 48MB.
- `START.bat` 이 하는 일:
  - 8095 포트가 이미 쓰이고 있으면 한글 안내를 띄우고 멈춘다.
  - 아니면 톰캣을 켜고, curl 로 응답을 확인한 뒤 브라우저를 연다.
  - 창을 닫으면 꺼진다.

## 터진 것 / 헛짚은 것
- **첫 실행 시험이 실패**
  - 원인: 묶음 잘못이 아니었다. Git Bash 에서 `cmd //c` 로 넘길 때 따옴표가 글자 그대로 들어갔다.
  - 고친 방법: PowerShell 에서 따옴표를 감싸 실행했다.
- **빌드 스크립트 한 줄이 깨짐**
  - 원인: 스크립트를 파이썬으로 고치다가 `newline='\r\n'` 이 진짜 줄바꿈으로 들어가 줄이 쪼개졌다.
  - 고친 방법: README 채우기를 따로 파일(`fill_readme.py`)로 뺐다.
- **이미지 검사에서 비공개 이름 패턴이 걸림**
  - `explore.jpg` 압축 데이터 안의 우연한 바이트(`JhY`)였다. 메타데이터는 없다.

## 확인한 것
- zip 을 한글 · 띄어쓰기가 든 새 폴더에 풀어서 켰다.
  - 키 없는 묶음: 플래너에서 「인증키가 없어요」 안내가 나왔고, 쪽은 `</html>` 까지 끝났다.
  - 키 든 묶음: 경주 플래너가 실제 응답으로 끝까지 나왔다(101KB).
  - 포트는 127.0.0.1 에서만 열렸다.
  - `/` 로 들어가면 `/TourWeather/` 로 넘어갔다.
  - 이미 켜진 상태에서 하나를 더 켜면 포트 안내가 나오고 종료 코드 1로 끝났다.
- 캡처 10장을 찍는 동안 콘솔 오류 · 페이지 오류는 0이었다.
- 새 파일(README · tools · 이미지)에서 인증키 문자열은 0건이었다. 원문 · 인코딩 · 디코딩 세 형태로 찾았다.

## 남긴 것 / 안 한 것
- 드라이브에는 아직 안 올렸다. 키를 넣을지와 공유 범위를 정해야 한다.
- 다른 PC에서는 시험하지 않았다.
  - 인터넷에서 받은 파일이라 보안 경고 창이 뜨는지 보지 않았다.
  - 방화벽 창은 127.0.0.1 에만 열기 때문에 안 뜰 것으로 보지만, 직접 확인하지는 않았다.
- 맥용 묶음은 없다.
